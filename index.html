02What I do now

These days I build websites

Most of my sites run on WordPress. When WordPress would only get in the way, I code them from scratch instead.

  • WordPress sites

    WordPress and Elementor sites you can update yourself, without calling me every time a price changes.

  • Custom code

    When WordPress isn’t the right fit, I write it in HTML, CSS, JavaScript or Next.js. And yes, it works on phones.

    WooCommerce shops that take card and mobile money through Paystack. Donation pages and enquiry forms too.

03How a project goes

Here’s how we’d work together

You see the design before I build anything, and once the site is live you can update it yourself.

  1. 01

    We talk

    A call about what the site is for and who will use it. You show me whatever content you already have, and we agree on scope and a timeline.

  2. 02

    I design it in Figma

    You see every page and ask for changes before I write any code.

  3. 03

    I build it

    Usually in WordPress and Elementor, with whatever forms or payments you need. I check it on my phone as I go.

  4. 04

    We launch

    I set up analytics and show your team how to update things. If anything breaks after that, message me.
